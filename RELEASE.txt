AgentArena — Release Notes
==========================

Version 01.03.00 (2026-07-21)
------------------------------
Phase v01.03 — Match, seats & lobby REST.
Git tag: opus-sonnet-v01.03.00 (namespaced — this branch's independent build).

- FastAPI app: server/main.py builds the app via create_app(...) with a lifespan
  that runs init_models on startup, GET /api/v1/health, and a per-request
  Repository dependency; server/schemas.py adds the lobby request/response
  models. The app is now runnable with `uvicorn server.main:app`.
  (ARENA-OPUS-SONNET-008)
- Auth tokens: server/auth.py issues an opaque token that IS the
  participant_id, with the frozen IssuedToken value object and validate_token
  (None for unknown/other-match tokens). Identity is keyed by token, never by
  display name. (ARENA-OPUS-SONNET-009)
- Lobby REST: POST /api/v1/lobby/match creates a match and returns its id;
  POST /api/v1/lobby/join returns 404 for an unknown match, else records the
  participant (carrying is_spectator) and returns the token.
  (ARENA-OPUS-SONNET-010)
- Seat helpers: server/match.py provides thin assign_symbol / release_seat
  wrappers over the Repository. End-to-end tests prove the seat-by-token
  identity against real join tokens: two players get X/O, a third gets no
  seat, a spectator is never seated, and two joins named "Human" get distinct
  seats. (ARENA-OPUS-SONNET-011)
- Quality: 81 tests passing; mypy --strict clean; no paid model calls anywhere
  (lobby is REST + DB only; the LLMClient seam arrives in v02.01).

Version 01.02.00 (2026-07-21)
------------------------------
Phase v01.02 — Persistence layer (SQLite). The durable substrate every later
phase reads/writes through the Repository.
Git tag: opus-sonnet-v01.02.00 (namespaced — this branch's independent build).

- Async SQLite persistence: an async SQLAlchemy engine over sqlite+aiosqlite
  (config-driven URL), NullPool (avoids pooled-connection flakiness across many
  short-lived test engines), a connect-time PRAGMA foreign_keys=ON, and
  init_models(). The four ORM tables (matches, participants, moves,
  chat_messages) with match_id foreign keys and UNIQUE(match_id, symbol);
  opaque move payloads stored as JSON so their type round-trips.
  (ARENA-OPUS-SONNET-004)
- Repository: the single access seam for durable state — create_match,
  get_match, add_participant, log_move, log_chat. State survives a process
  restart. (ARENA-OPUS-SONNET-005)
- Seat rule (§5.2): assign_symbol / release_seat, keyed by token not display
  name — spectators never get a seat; a third player gets none; reconnects are
  idempotent; a race between two concurrent assignments resolves (not just
  detects) to distinct symbols via a bounded retry (code review fix).
  (ARENA-OPUS-SONNET-006)
- Reconstruction: reconstruct_game replays the ordered move log through a
  fresh TicTacToe (no serialize step on GameInterface); current_turn is
  move-count parity, None once over. (ARENA-OPUS-SONNET-007)
- Quality: 62 tests passing; mypy --strict clean; no paid model calls anywhere
  (persistence is pure server/DB logic — the LLMClient seam arrives in v02.01).

Version 01.01.00 (2026-07-21)
------------------------------
Phase v01.01 — Project skeleton & the game engine. The first stable seam
(GameInterface) plus its first concrete implementation, verified entirely in
isolation.
Git tag: opus-sonnet-v01.01.00 (namespaced — this branch's independent build).

- Project skeleton: pyproject.toml (pytest + strict mypy config, plus
  [build-system]/[tool.setuptools] pinning the three installable packages) and
  the games/server/agent package layout, with a smoke test proving the
  toolchain runs and the packages import. (ARENA-OPUS-SONNET-001)
- GameInterface seam: the abstract game plug-in — get_state, get_valid_moves,
  apply_move, is_game_over — with a contract test pinning the §4.1 method
  signatures and abstractness. (ARENA-OPUS-SONNET-002)
- TicTacToe engine behind the seam: 9-cell board, 8 winning lines, "draw" on a
  full board; apply_move is the sole legality authority and never raises on
  bad input (out-of-range / occupied / wrong-type). Ships an exhaustive unit
  suite (a win on every line, draw detection, illegal rejection per category,
  valid-moves shrink invariant). (ARENA-OPUS-SONNET-003)
- Quality: 36 tests passing; mypy --strict clean on source and tests; no paid
  model calls anywhere (pure logic — the LLMClient seam arrives in v02.01).
