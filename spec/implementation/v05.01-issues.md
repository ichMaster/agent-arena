## v05.01 Tasks

### ARENA-032 — Create AgentProfile Pydantic Schema and YAML Definitions

**Description:**
To move away from hardcoded agent personas, we need a formalized configuration system. We will define an `AgentProfile` Pydantic schema and use it to validate loaded YAML configurations.

**What needs to be done:**
- Create `client/profile.py` containing a Pydantic `BaseModel` called `AgentProfile`.
- The schema should define fields: `name` (str), `model_type` (str), `temperature` (float), `system_prompt` (str), and `memory_limit` (int).
- Create a `profiles/` directory at the root of the project.
- Create at least two sample YAML profiles (e.g., `aggressive_bot.yml` and `defensive_bot.yml` or `cowardly_bot.yml`).
- Add logic in `client/profile.py` to parse a YAML file using PyYAML and validate it through the `AgentProfile` schema.
- Add `PyYAML` to `requirements.txt`.

**Dependencies:** None

**Expected result:**
Developers can define arbitrary agent personas in YAML, and the system can load and validate them strictly into Python objects.

**Acceptance criteria:**
- [ ] `AgentProfile` Pydantic model is fully defined.
- [ ] PyYAML is installed and used to load YAML profiles.
- [ ] At least two distinct YAML profile files exist in the `profiles/` directory.
- [ ] A test or function successfully validates a YAML file into an `AgentProfile` object.
