## v01.01 Tasks

### ARENA-001 — Project skeleton and health probe

**Description:**
Sets up the foundational FastAPI server for the Agent Arena project. This touches the `server/` module by creating the initial app instance and routing.

**What needs to be done:**
- Create `requirements.txt` locking versions for `fastapi`, `uvicorn`, `pydantic`, `websockets`, `pytest` and `sqlalchemy`.
- Initialize the FastAPI app instance in `server/main.py` with CORS middleware allowing all origins (for local development).
- Implement `/api/v1/health` endpoint returning a simple `{ "status": "ok" }`.

**Dependencies:** None

**Expected result:**
The FastAPI server boots successfully via Uvicorn and responds to HTTP GET health checks.

**Acceptance criteria:**
- [ ] Requirements file exists and installs cleanly.
- [ ] FastAPI instance is configured with CORS.
- [ ] **Unit test:** Pytest correctly tests the `/api/v1/health` route using `TestClient`.
- [ ] Ties to DoD: HTTP endpoints return `200 OK` with valid JSON.

### ARENA-002 — Match generation endpoint

**Description:**
Implements the lobby endpoint allowing clients to create a new, unique game instance before connecting. Touches the `server/` module.

**What needs to be done:**
- Implement `/api/v1/lobby/match` HTTP POST endpoint in `server/main.py`.
- The endpoint must generate a unique `match_id` (UUID4) and return it in a structured JSON payload: `{"match_id": "<uuid>"}`.
- Create Pydantic response schemas for the endpoint.

**Dependencies:** ARENA-001

**Expected result:**
Clients can POST to the lobby and receive a unique match UUID to use for subsequent joins.

**Acceptance criteria:**
- [ ] Endpoint `/api/v1/lobby/match` is implemented and documented via Swagger.
- [ ] **Unit test:** Pytest confirms a valid UUID string is returned in the JSON payload.
- [ ] Ties to DoD: HTTP endpoints return `200 OK` with valid JSON containing UUIDs.

---

### ARENA-003 — Auth Token generation endpoint

**Description:**
Implements the lobby join endpoint which issues the temporary opaque tokens required to secure WebSocket connections. Touches the `server/` module.

**What needs to be done:**
- Implement `/api/v1/lobby/join` HTTP POST endpoint.
- Accept a Pydantic payload containing `match_id` (string) and `player_name` (string).
- Generate a temporary opaque Auth Token (a random UUID/string for now) and return it: `{"token": "<token>"}`.

**Dependencies:** ARENA-002

**Expected result:**
Clients can register for a specific match and receive an authorization token to use during the WebSocket handshake.

**Acceptance criteria:**
- [ ] Endpoint `/api/v1/lobby/join` is implemented.
- [ ] Input payload is strictly validated using Pydantic.
- [ ] **Unit test:** Pytest confirms the endpoint rejects missing fields (422) and returns a valid token for correct inputs.
- [ ] Ties to DoD: HTTP endpoints return `200 OK` with valid JSON containing tokens.
