## v03.01 Tasks

### ARENA-018 — Agent CLI skeleton & Lobby Integration

**Description:**
Create the foundation for the standalone Python Agent Client. This CLI application will connect to the game server via HTTP to acquire authentication tokens.

**What needs to be done:**
- Create `client/agent.py` script utilizing `asyncio` and `aiohttp` (or `requests`/`httpx`).
- Setup `python-dotenv` to load `.env` variables (e.g. `GEMINI_API_KEY` for the upcoming Gemini-3.1-pro integration).
- Implement an HTTP call to the server's `/api/v1/lobby/join` endpoint to acquire an Auth Token using a provided Match ID.
- Add CLI arguments (e.g. `argparse`) allowing a developer to pass the Match ID and Server URL on boot: `python client/agent.py --match-id <UUID>`.

**Dependencies:** None

**Expected result:**
A runnable python script that can successfully hit the local server lobby and print out an acquired Auth Token.

**Acceptance criteria:**
- [ ] Agent script handles CLI arguments correctly.
- [ ] Agent successfully fetches an Auth Token from the server.
- [ ] Errors (like invalid Match ID or offline server) are caught and printed gracefully.

### ARENA-019 — Agent WebSocket loop & Event Parsing

**Description:**
Extend the Agent CLI to establish a WebSocket connection and implement the core event loop that listens to server payloads.

**What needs to be done:**
- Install the `websockets` package in `requirements.txt`.
- Establish the WebSocket connection `ws://...` using the Auth Token from ARENA-018.
- Build the `async for message in websocket:` listener loop.
- Parse incoming JSON messages and route them based on the `event` key.
- Setup placeholder functions/logging for `state_update` and `chat_message` events.
- Ensure the agent detects when it is its turn (e.g. via `state_update` checking `current_turn` vs agent's assigned symbol).

**Dependencies:** ARENA-018

**Expected result:**
The Agent connects to an active match, maintains a persistent connection, and logs all events happening in the match in real time on standard output.

**Acceptance criteria:**
- [ ] `client/agent.py` connects to the WebSocket securely.
- [ ] Event loop parses JSON correctly without throwing unhandled exceptions on bad payloads.
- [ ] `state_update`, `game_over`, and `chat_message` events are distinguished and logged to stdout.
- [ ] Meets Phase DoD: The Agent CLI can connect to the server and cleanly log incoming network events to stdout.
