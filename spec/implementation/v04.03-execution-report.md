- `renderBoard(board, currentTurn, validMoves)`: writes X/O text + glow class per cell, toggles `.active` on the player cards, and marks a cell `.disabled` unless it's genuinely this client's turn, the cell is empty, and it's in `valid_moves`. `handleCellClick` sends `submit_move`; wired to all 9 cells.
- `initPlayerCards`: sets each card's displayed symbol from the real assigned symbol rather than assuming the human is always X (symbol assignment is by connection order, not identity).
- `renderChat`/`addMessage`: safe DOM-based message rendering (`createElement`/`textContent`), styled by sender (`system`/`user`/`agent` — the prototype's `innerHTML`-with-string-interpolation was not carried forward, since chat text and sender names are attacker-controlled once real players are chatting over the wire).
- Chat input/button enable on `ws.onopen`, disable on `close`; form submit sends the `chat` action.
- `handleGameOver`: freezes every cell, updates status text with the win/draw result, logs a system message. `error` events now render as a chat message instead of only `console.log`.
