## Findings

### #1 🟡 Static chat count (LOW) — DEFER → v05
`#chat-count` never updates; no `joined`/`state_update` payload carries participant counts. A
faithful count needs a protocol addition — out of MVP scope (web_ui_spec §10). Homed to v05.

### #2 🟡 Both cards "Observer" (LOW) — accepted
When watching, `renderPlayers` sets both player cards' role line to "Observer". Semantically the two
*players* aren't observers, but web_ui_spec §4.3 lists "Observer" as the watching role line and the
turn banner already reads "Observing — … to move". Cosmetic; kept per the spec.
