# Code Review & Fix Recommendations — v04.02 (arena orchestration script, v04 release gate)

**Date:** 2026-07-21 · **Reviewer:** Claude Opus 4.8, via `/ship-solution`
**Scope:** `scripts/run_arena.sh` and its static tests.
**Method:** manual adversarial read of shell semantics — quoting, `set -euo pipefail` interaction with
command substitution + backgrounded jobs, trap/signal behavior, and injection surface.

## Recommendation summary
*No findings.* Every value expansion (match id, profile paths) is double-quoted; `set -euo pipefail`
aborts on a failed `curl`/JSON-parse rather than proceeding with an empty match id; the wait-for-agent-1
loop has an explicit liveness check so a crashed agent 1 fails fast instead of looping the full timeout.

## Notes considered and set aside (not findings)
- **`cleanup()` can run twice on Ctrl-C** (INT trap, then the EXIT trap). Not a bug: `kill -0` guard +
  `rm -f` are idempotent — a second call is a no-op. Standard belt-and-suspenders trap pattern.
- **Agent 2 has no join-liveness check of its own.** Out of scope: the DoD requires only agent1→agent2
  *ordering* for deterministic seats; an agent-2 failure surfaces immediately in the tailed logs.
- **A crafted `match_id` from a compromised server.** Not exploitable: it's only ever a *quoted*
  argument to `agent/agent.py`, never `eval`'d; and this is the local-first dev server (§12).

## What's solid
`MATCH_ID` and both profile paths are always `"$quoted"` — no word-splitting/glob surface. Using
command substitution in an *assignment* (`MATCH_ID="$(… | "$PYTHON" -c …)"`) with `set -e` means a
failed curl or invalid JSON aborts immediately rather than limping forward. The `PYTHON` fallback
(`.venv/bin/python` → `python3`) and the repo-root `cd` match the reconciled shipped-CLI assumptions
(no `--symbol`; ordering is the only lever). Zero paid calls in the suite — the script's real Haiku
calls only happen in an actual demo run, never under test.

## Architecture impact
None — an operator script over already-shipped surfaces (lobby REST, agent CLI); no seam changed.
