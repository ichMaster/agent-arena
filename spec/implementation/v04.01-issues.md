## v04.01 Tasks

### ARENA-025 — Break UI Prototype into Clean Structure

**Description:**
We currently have a `test_client.html` file that serves as a rudimentary UI. For Phase 4, we need to establish a cleaner, more modular frontend structure before we apply heavy styling.

**What needs to be done:**
- Refactor the existing HTML into a semantic structure (Header, Main Content, Sidebar/Chat).
- Extract embedded CSS into a dedicated `styles.css` file.
- Set up a basic `index.html` as the new entry point for the frontend Web UI.

**Dependencies:** None

**Expected result:**
A clean separation of HTML and CSS, providing a solid foundation for the new design system.

**Acceptance criteria:**
- [ ] HTML is semantic and well-structured.
- [ ] All CSS is moved to external stylesheet(s).
- [ ] No JavaScript is added or modified in this task.

---

### ARENA-026 — Implement Glassmorphism Styling System

**Description:**
The application must look modern, premium, and visually striking. We will implement a Glassmorphism design system using `backdrop-filter` and vibrant gradients.

**What needs to be done:**
- Define CSS custom properties (variables) for the vibrant color palette, dark mode background, and glass pane effects.
- Implement the Glassmorphism utility classes (`background: rgba(...)`, `backdrop-filter: blur(...)`, subtle borders, and box shadows).
- Create dynamic glowing accents specifically for the 'X' and 'O' symbols.
- Ensure typography uses a modern Google Font (e.g., Inter or Outfit).

**Dependencies:** ARENA-025 (#25)

**Expected result:**
The basic components (buttons, panels, text) reflect a high-end, dynamic Glassmorphism aesthetic.

**Acceptance criteria:**
- [ ] Global CSS variables for the color palette are defined.
- [ ] Glassmorphism styling is successfully applied to main container elements.
- [ ] Glowing accents for player symbols are implemented.
- [ ] Modern typography is active.

---

### ARENA-027 — Scaffold CSS Grid & Flexbox Layouts

**Description:**
With the styling system in place, we need to construct the specific layout for the Tic-Tac-Toe board and the Chat Area sidebar.

**What needs to be done:**
- Implement a responsive CSS Grid for the 3x3 game board, ensuring cells are perfectly square and scale appropriately.
- Implement a Flexbox layout for the Chat Area, pinning it to the side on desktop and stacking it on mobile.
- Structure the Player Cards (showing X and O) above or beside the board.

**Dependencies:** ARENA-026 (#26)

**Expected result:**
The static HTML renders a perfectly laid-out board and chat sidebar using the new Glassmorphism styles, ready for JavaScript integration.

**Acceptance criteria:**
- [ ] The 3x3 board uses CSS Grid and cells are correctly proportioned.
- [ ] The Chat area uses Flexbox for message stacking and input alignment.
- [ ] The layout is responsive (adapts to smaller screens).
- [ ] Static HTML renders correctly without JavaScript.
