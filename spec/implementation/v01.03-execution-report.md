## Bugs found and fixed mid-phase

1. **`/lobby/match` never persisted a match row.** Once chat logging depended on the `matches` FK (enabled in ARENA-007), every chat message would have failed `IntegrityError`. Fixed by having `create_match` insert via the `Repository`.
2. **`@app.on_event("startup")` is deprecated**, and more importantly a bare `TestClient(app)` module global never triggers it at all — so the DB schema was silently never created under test. Replaced with a `lifespan` context manager and switched the test client to an entered (not just constructed) `TestClient`.
