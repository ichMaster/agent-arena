## What's solid
Because every test patches `AsyncAnthropic`, a mismatched real-call signature would be invisible to the
suite — so it was checked directly against the installed SDK: `messages.parse(..., output_format=schema)`
→ `.parsed_output` is a valid, supported call (`parse` accepts `output_format`; `ParsedMessage` exposes
`parsed_output`). Structured output is forced at the client and returned validated — the caller never
parses raw text, and an unparsed reply raises rather than silently returning `None`. The secret is
handled correctly per §9: `ANTHROPIC_API_KEY` is read only in `agent/llm.py::load_api_key`, never
logged, and a grep confirms neither `server/` nor `web/` references it. `create_llm_client` keeps
`agent/agent.py` free of any concrete-client import (unknown type → clear `ValueError`, empty key →
clear `RuntimeError`). The `LLMClient` seam imports nothing from `server/` (pinned by the contract
test), and the Haiku model id is a single constant confirmed against the live model list.

## Architecture impact
None — §4.2/§7.3/§9 implemented exactly as documented; no contract changed.
