## v05.02 Tasks

### ARENA-033 — Refactor Agent CLI to Consume Dynamic YAML Profiles

**Description:**
The Agent CLI (`client/agent.py`) currently hardcodes the prompt, personality, and model selection. It needs to be refactored to parse an `AgentProfile` from a given YAML file and use those settings at runtime.

**What needs to be done:**
- Update `argparse` in `client/agent.py` to accept a `--profile` parameter (path to the `.yml` file). Make this parameter required.
- Load the YAML file using `AgentProfile.load_from_yaml()`.
- Refactor `MemoryWindow` to respect the `memory_limit` specified by the profile.
- Replace the hardcoded persona prompt string with the `system_prompt` from the profile.
- Pass the profile's `temperature` down to the `GeminiClient`.
- Ensure the chat logs and console output identify the Agent by its profile `name` rather than a generic identifier.

**Dependencies:**
- ARENA-032 (AgentProfile schema)

**Expected result:**
Developers can boot the agent with completely different playstyles just by swapping the `--profile` argument.

**Acceptance criteria:**
- [ ] `client/agent.py` requires a `--profile` argument.
- [ ] The agent correctly parses and acts according to the `system_prompt` of the loaded profile.
- [ ] The agent respects the `memory_limit` and `temperature` fields.
- [ ] A successful run can be achieved using `python client/agent.py --match-id <id> --symbol O --profile profiles/aggressive_bot.yml`.
