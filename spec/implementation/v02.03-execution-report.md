## Bugs found and fixed mid-phase

1. **Self-close re-receive crash (ARENA-017).** When a game ends, `close_room` closes every connection in the room server-side — including the sender's own socket, from within that same connection's handler coroutine. The loop then called `receive_json()` again on the now-closed socket, raising an unhandled `RuntimeError` ("WebSocket is not connected") instead of the expected `WebSocketDisconnect`. Fixed by checking `websocket.application_state` after handling each message and breaking the loop if the server already closed it.
2. A first draft of the invalid-move integration test had an incorrect premise (assumed WS *connection* order determined X/O symbol assignment, when it's actually first `submit_move` *sender* order) — caught immediately by the test itself failing for the right reason; corrected the test, not the implementation.
