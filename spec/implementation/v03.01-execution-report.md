## Highlights

- **Static mount:** `/ui` served from a CWD-independent `WEB_DIR`; the `no-store` middleware matches
  `/ui` **exactly** (`/ui` or `/ui/…`), never a loose `startswith("/ui")` — so `/api/*` keeps normal
  caching and a hypothetical `/uixyz` wouldn't be stamped.
- **Shell:** the full arena layout mirrors `ui_prototype.html` (glass tokens, neon X/O, real `<button>`
  cells for a11y, responsive ≤860px collapse, reduced-motion honored); self-contained, no CDN.
- **app.js:** one WebSocket per connection; the **full** match id is displayed (never sliced — it's
  copied into the agent CLI); a `routeEvent` case per server event; `isGameActive` resets on every new
  connection (the §7 second-match guard). `window.arena` keeps it testable without a DOM.
