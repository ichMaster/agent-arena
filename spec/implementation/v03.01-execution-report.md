## Protocol gap found and fixed mid-phase

Nothing in the Phase 1/2 WS contract ever told a connecting client which symbol (X/O) it held — `Match.assign_symbol` only ran lazily on a player's first `submit_move`. An agent needs to know its own symbol *before* ever moving, to decide whether to act on the first turn. Fixed by sending a one-time `joined` event (assigned symbol + current board/turn) immediately after every WS `accept()` (`server/websockets.py::send_joined_event`, wired into `server/main.py`). This moves symbol assignment from first-move order to connection order, which required updating 6 already-committed Phase 1/2 tests in `tests/test_server.py` that assumed their first `receive_json()` would be their own requested message.
