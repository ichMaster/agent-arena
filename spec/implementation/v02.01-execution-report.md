## Pre-execution fix

Before starting, the baseline suite was found **flaky** (`test_ws_game::test_full_game_draw`
intermittently failed with `sqlite3.OperationalError` under the full suite — undisposed async test
engines leaking aiosqlite connections that were GC-terminated mid-operation). Fixed in `feee52f` by
using **`NullPool`** for the SQLite engine (no pooled connections to leak; FK PRAGMA re-runs on every
connection). Suite then green + deterministic (5× runs) before execution began.
