## v02.03 Tasks

### ARENA-016 — Match Orchestrator & WS Integration

**Description:**
Wire the `TicTacToe` game engine into the existing WebSocket `ConnectionManager`. This introduces the authoritative "Match" context that actively listens for `submit_move` WebSocket JSON payloads and processes them through the engine.

**What needs to be done:**
- Create `server/match.py` or modify `websockets.py` to manage active `Match` instances holding a `TicTacToe` state.
- Parse incoming WebSocket payloads for `action="submit_move"`.
- Validate the move against the engine's `apply_move` API.
- If valid, broadcast a `state_update` JSON payload to all connected clients in that match room.
- If invalid, return an `error` payload exclusively to the offending player.
- Upon `is_game_over()` indicating a winner or draw, broadcast a `game_over` event and gracefully terminate the WebSockets in that room.

**Dependencies:** None

**Expected result:**
The WebSocket server fully negotiates a live game of Tic-Tac-Toe between two connected clients.

**Acceptance criteria:**
- [ ] Active match state is preserved during a WebSocket lifecycle.
- [ ] Valid moves broadcast `state_update` payloads to all players.
- [ ] Invalid moves send an isolated `error` payload back to the offending client without disrupting the game.
- [ ] When the game terminates, a `game_over` event is fired and the connections close gracefully.

### ARENA-017 — Concurrent Testing for Match Lifecycle

**Description:**
Extend the `pytest-asyncio` test suite to simulate two distinct players concurrently connecting to the same match ID via WebSockets and playing a full game end-to-end.

**What needs to be done:**
- Extend `tests/test_server.py`.
- Instantiate two concurrent `TestClient` sessions targeting the same match room.
- Play a valid sequence of moves triggering a `game_over` event.
- Ensure `state_update` events are sequentially verified in the assertions.
- Trigger at least one invalid move to ensure the `error` state doesn't crash the server.

**Dependencies:** ARENA-016

**Expected result:**
Integration tests proving two distinct WebSocket clients can connect to a match ID and play a full game of Tic-Tac-Toe until one wins or they draw.

**Acceptance criteria:**
- [ ] Pytest spins up an ASGI client with two concurrent WebSocket channels.
- [ ] 100% of game states (valid moves, invalid moves, game_over) are verified in tests.
- [ ] Meets Phase DoD: 2 distinct WebSocket clients can connect to a match ID and play a full game of Tic-Tac-Toe until one wins or they draw.
