## Highlights

- **Engine/schema:** async engine over `sqlite+aiosqlite` with `NullPool` + a connect-time
  `PRAGMA foreign_keys=ON` listener; four SQLAlchemy-2.0 typed tables with `UNIQUE(match_id, symbol)`
  and an opaque `JSON` `move` column. `create_engine`/`create_session_maker` bind a throwaway temp-file
  DB in tests, so `./arena.db` is never touched.
- **Repository:** the single access seam — no ad-hoc SQL in handlers. The opaque move payload
  round-trips untouched (verified with a dict payload).
- **Seat rule (§5.2):** built **race-safe from the start** — `assign_symbol` retries on the
  `UNIQUE(match_id, symbol)` `IntegrityError` rather than letting a concurrent claim crash. A real
  `asyncio.gather` race on two separate sessions resolves to distinct seats, deterministic across
  repeated runs.
- **Reconstruction:** `reconstruct_game` replays the move log through a fresh `TicTacToe`; the server
  holds no board state of its own. `current_turn` is parity-derived and `None` at/after game-over.
