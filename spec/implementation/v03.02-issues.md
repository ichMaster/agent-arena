## v03.02 Tasks

### ARENA-020 — LLMClient Wrapper & Gemini Integration

**Description:**
Integrate the Google Generative AI SDK for Gemini into the Python Agent. We want to abstract the raw SDK calls behind a unified `LLMClient` interface so we can easily swap models later in Phase 5.

**What needs to be done:**
- Add `google-genai` to `requirements.txt` (the official SDK for Gemini).
- Create `client/llm.py` containing a base `LLMClient` class with a `async def generate_response(prompt: str) -> str:` interface.
- Implement `GeminiClient(LLMClient)` which initializes the Gemini SDK using `os.getenv("GEMINI_API_KEY")`.
- Hardcode the model targeting **`gemini-3.1-pro`** (as per user request).
- Implement a basic test script or log line to confirm the LLM generates a response when hit.

**Dependencies:** None

**Expected result:**
The `client` directory has a working, abstracted `GeminiClient` that can receive text prompts and asynchronously return text generations from `gemini-3.1-pro`.

**Acceptance criteria:**
- [ ] `google-genai` installed and locked in `requirements.txt`.
- [ ] `GeminiClient` is built and leverages the `.env` `GEMINI_API_KEY`.
- [ ] Uses `gemini-3.1-pro` model specifically.
- [ ] Asynchronous text generation works without blocking the main event loop.

### ARENA-021 — Prompt Builder, Persona & Memory Window

**Description:**
The Agent needs context to play the game. We need to construct a highly structured prompt by combining its system persona, recent game history, and the current board state.

**What needs to be done:**
- Define a `MemoryWindow` class in `client/agent.py` or a new `client/memory.py` that maintains a rolling buffer of the last 10 chat messages and moves.
- Update the WebSocket listener (built in v03.01) to push incoming events (`chat_message`, `state_update`) into the `MemoryWindow`.
- Hardcode the System Persona: *"You are an arrogant Tic-Tac-Toe master. Never lose."*
- Create a prompt builder function that dynamically stitches together: 
  1. The Persona.
  2. The `MemoryWindow` context (chat history & recent events).
  3. The Current Board State (from `state_update`).
  4. Available Valid Moves (e.g. empty spaces).
- Wire it so that when it is the Agent's turn, it executes the prompt builder and hits `LLMClient.generate_response(prompt)`.

**Dependencies:** ARENA-020

**Expected result:**
When the Agent detects it is its turn via the WebSocket, it formulates a rich context prompt, sends it to Gemini, and logs Gemini's response to the terminal. (Note: Translating the response *back* into a WebSocket action is reserved for v03.03).

**Acceptance criteria:**
- [ ] `MemoryWindow` correctly tracks the last N events without memory leaks.
- [ ] Prompt correctly injects board state and valid moves.
- [ ] When it's the agent's turn, a prompt is sent to `gemini-3.1-pro`.
- [ ] The raw string response from the LLM is printed out cleanly to `stdout`.
- [ ] Meets Phase DoD: When it is the agent's turn, it successfully hits the LLM API with a highly structured contextual prompt.
