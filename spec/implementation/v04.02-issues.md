## v04.02 Tasks

### ARENA-028 — Implement Lobby HTTP Integration (Match & Join)

**Description:**
To connect to the game server, the Web UI must first negotiate authentication by creating or joining a match via standard HTTP endpoints.

**What needs to be done:**
- Create `web/app.js` and link it in `index.html`.
- Implement an `async function hostMatch()` that calls `POST /api/v1/lobby/match`.
- Implement an `async function joinExistingMatch()` that prompts the user for a Match ID and calls `POST /api/v1/lobby/join` to retrieve the Auth Token.
- Bind these functions to the 'Host New Match' and 'Join Match' buttons in the DOM.

**Dependencies:** None

**Expected result:**
Clicking the lobby buttons successfully hits the local FastAPI backend and retrieves a valid Match ID and Auth Token.

**Acceptance criteria:**
- [ ] `app.js` contains the HTTP fetch logic for `/match` and `/join`.
- [ ] Button clicks successfully trigger network requests.
- [ ] The Match ID is visually updated in the DOM header (`#match-id-display`).

### ARENA-029 — Establish Native WebSocket Connection & Event Router

**Description:**
Once the UI has an Auth Token, it needs to establish the real-time WebSocket connection and route incoming server push events to the DOM.

**What needs to be done:**
- After successfully joining a match, instantiate a `new WebSocket(...)` passing the Auth Token in the query string.
- Implement `ws.onopen` and `ws.onclose` to toggle the Server Status dot (`#connection-dot`) between green (`.connected`) and red (`.disconnected`).
- Implement `ws.onmessage` to parse incoming JSON payloads and log them or prepare a switch-case router for event types: `state_update`, `game_over`, and `chat_message`.

**Dependencies:** ARENA-028 (#28)

**Expected result:**
The Web UI successfully holds a live socket connection with the backend, visually indicating connectivity.

**Acceptance criteria:**
- [ ] The browser successfully connects via `wss://` (or `ws://` locally).
- [ ] The Server Status indicator turns green upon connection and red upon disconnect.
- [ ] The incoming JSON payloads from the server are successfully parsed in the `onmessage` handler.
