## v02.01 Tasks

### ARENA-012 — Abstract GameInterface Class

**Description:**
Define the strict base interface (`GameInterface`) that all future game engines (Tic-Tac-Toe, Checkers, etc.) must implement. This establishes the polymorphic seam between the game rules and the WebSocket server orchestration.

**What needs to be done:**
- Create the package `games/` with an `__init__.py`.
- Create `games/interface.py`.
- Define an abstract base class `GameInterface` using Python's `abc` module.
- Define `@abstractmethod get_state(self) -> dict`.
- Define `@abstractmethod get_valid_moves(self) -> list`.
- Define `@abstractmethod apply_move(self, player: str, move: any) -> bool`.
- Define `@abstractmethod is_game_over(self) -> str | None`.

**Dependencies:** None

**Expected result:**
A standalone abstract class that can be inherited by concrete game implementations, enforcing uniform state and move mechanics.

**Acceptance criteria:**
- [ ] `GameInterface` inherits from `abc.ABC`.
- [ ] All four methods are marked with `@abstractmethod`.
- [ ] The module imports no FastAPI, WebSocket, or database dependencies.
- [ ] **Unit test:** Attempting to instantiate `GameInterface` directly throws a `TypeError`.
- [ ] Contributes to DoD: The interface is completely decoupled from WebSockets or HTTP logic.

### ARENA-013 — Enforce MyPy validation on games

**Description:**
Ensure that the `games/` module strictly adheres to Python type hinting, as the server orchestration will heavily rely on these contracts.

**What needs to be done:**
- Add `mypy` to the project's dependencies (e.g. `requirements-dev.txt` or `requirements.txt`).
- Add basic `mypy.ini` configuration at the root of the project to enforce strict typing on the `games/` directory.
- Ensure the `games/interface.py` file fully passes MyPy checks.

**Dependencies:** ARENA-012

**Expected result:**
The CI or local build process can validate typing contracts against the game interface.

**Acceptance criteria:**
- [ ] `mypy` successfully analyzes `games/interface.py` without errors.
- [ ] Type hints in `interface.py` are robust (e.g. `typing.Dict`, `typing.List`, `typing.Any`, `typing.Optional`).
- [ ] Meets Phase DoD: Linter/MyPy typing checks ensure abstract definitions are enforced.
