## v05.03 Tasks

### ARENA-034 — Create Swarm Script to Orchestrate AI vs AI Matches

**Description:**
Now that agents can accept arbitrary profiles, we want to automate the process of pitting them against each other in a zero-human game. We will build a shell script (`run_swarm.sh`) that acts as an orchestrator.

**What needs to be done:**
- Create `scripts/run_swarm.sh`.
- The script should use `curl` to hit the `POST /api/v1/lobby/match` endpoint to create a new match and parse the returned UUID.
- The script should print the Match ID and provide a link for the developer to open the Web UI spectator mode (e.g. `http://localhost:8000/ui`).
- The script should wait a few seconds (or prompt the user to hit Enter) to ensure they have the UI open.
- The script should then spawn two background instances of `python client/agent.py`:
  - Process 1: `--symbol X --profile profiles/aggressive_bot.yml`
  - Process 2: `--symbol O --profile profiles/cowardly_bot.yml`
- It should pipe or display the logs of both agents so the user can see them fighting in the terminal.

**Dependencies:**
- ARENA-033 (Agent CLI refactor)

**Expected result:**
Developers can run a single command and immediately observe two AI models fighting on the server.

**Acceptance criteria:**
- [ ] `scripts/run_swarm.sh` exists and is executable.
- [ ] Running the script successfully creates a match ID and launches two agent instances.
- [ ] Both agents connect to the server and successfully complete a game against each other.
