## v03.03 — Chat & the Observer role

### ARENA-OPUS-OPUS-030 — Chat — post `chat` + render `chat_message` / system / error lines

**Description:** wire the chat panel (web_ui_spec §4.4, §6): submitting the form sends a `chat` action;
`chat_message` renders a bubble (self left/blue, other right/pink); `game_over`/`error` post system
lines. Touches: `web/app.js`.

**What needs to be done:**
- `renderChat(sender, message)`: append a `.msg` bubble to `#messages` — **`sender === mySymbol`** →
  `agent-x` (left/blue, "you"), else `agent-o` (right/pink, sender label); auto-scroll to newest.
  Escape text via `textContent` (no `innerHTML` for chat — untrusted content).
- `renderSystem(text)`: append a centered `.msg.system` line (used for "Match started", game-over,
  and surfaced errors).
- `#chat-form` submit handler → `sendAction('chat', { message })` (trimmed, non-empty); clear the
  input; **never render optimistically** — the server echoes it back as `chat_message`.
- `routeEvent`: `chat_message` → `renderChat`; `error` → `renderSystem('⚠ ' + detail)` (**closes
  v03.01 review #2**); `game_over` → also `renderSystem` a result line.
- Enable `#chat-input`/`#chat-send` when the socket opens **for a player**; keep them disabled before
  connect (Observer gating is ARENA-OPUS-OPUS-031).

**Dependencies:** None (extends the shipped `routeEvent`).

**Expected result:** two players exchange chat live, correctly styled self vs other; system lines
appear for game over and errors.

**Acceptance criteria:**
- [ ] Submitting chat sends `{action:"chat", payload:{message}}` (trimmed, non-empty); no optimistic render; input clears.
- [ ] `chat_message` renders self (`sender === mySymbol`) left/blue and others right/pink; auto-scrolls; text is `textContent`-escaped.
- [ ] `error` surfaces a system line (v03.01 review #2); `game_over` posts a result system line.
- [ ] **Integration test** (served asset): `app.js` defines `renderChat`/`renderSystem`, the chat form sends the `chat` action, self-detection uses `mySymbol` (not a name), and `error` routes to a system line. No LLM.
- [ ] Ties to DoD: players exchange chat live.

### ARENA-OPUS-OPUS-031 — Observer role view + seat-less watch (v03 gate)

**Description:** layer the read-only Observer role (web_ui_spec §5, game_spec §3.3): a `joined` with
`symbol:null` renders a watch-only view — cells never enabled, chat input suppressed, cards labelled
"Observer" — without claiming a seat, never crashing on the null symbol. Touches: `web/app.js`
(+ `index.html`/`styles.css` if a visual tweak is needed).

**What needs to be done:**
- Observer detection is **only** `mySymbol === null` from `joined` (§5 — never inferred otherwise).
- `renderPlayers`: when `mySymbol === null`, both cards keep default X/O labels with role "Observer"
  (no crash — no `null.toLowerCase()`); the active-turn highlight still follows `current_turn`.
- Chat input gating: enable `#chat-input`/`#chat-send` on connect **only when `mySymbol !== null`**;
  for an Observer they stay disabled (MVP read-only, §5). Board cells are never enabled for an
  Observer (already true — `renderBoard`'s `myTurn` is false when `mySymbol === null`).
- Confirm the shipped `spectateMatch()` → `joinAndConnect(id, true)` sends `spectator:true` (it does);
  add the end-to-end assertion.

**Dependencies:** ARENA-OPUS-OPUS-030.

**Expected result:** clicking **Observe** on an agent-vs-agent match shows the board + chat updating
live, read-only, without claiming a seat.

**Acceptance criteria:**
- [ ] `Observe` joins with `spectator:true`; the `joined` `symbol` is `null`; **no seat** is claimed (server-verified).
- [ ] Observer view: cells never enabled, chat input suppressed, cards show "Observer"; `initPlayerCards(null)` does not crash.
- [ ] Host/Join still default to `spectator:false` (Player role).
- [ ] **Integration test** (served asset + real server): `app.js`'s spectate action sends `spectator:true` and is distinct from Join; an **observer join against the real server yields `symbol:null` and no seat**, and a forced observer `submit_move` is refused server-side ("no seat"). No LLM, no paid call.
- [ ] Ties to DoD (v03 gate): watch an agent-vs-agent match read-only without a seat; a spectator's `submit_move` is refused server-side.
- [ ] **Flagged for review (not required in this issue):** a forced observer `chat` is currently accepted server-side — `review-and-fix-issues` closes it (server-side "observers cannot chat") as the observer-read-only-chat item v01.04's review deferred here.
