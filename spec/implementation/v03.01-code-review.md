# Code Review & Fix Recommendations — v03.01 (static UI shell & connection)

**Date:** 2026-07-21 · **Reviewer:** Claude Opus 4.8, via `/ship-solution`
**Scope:** the `/ui` mount + `no-store` middleware (`server/main.py`), the arena shell
(`web/index.html`, `web/styles.css`), and the connection wiring (`web/app.js`).
**Method:** manual adversarial read — the middleware's path match, the mount ordering, match-id
handling (truncation / injection), and the single-socket lifecycle.

## Recommendation summary

*No findings.* The mount is CWD-independent and matches `/ui` exactly (not a loose prefix); the shell
exposes every JS-targeted id; `app.js` opens exactly one socket, shows the **full** match id via
`textContent` (no truncation, no injection), and resets `isGameActive` on every new connection.

## Findings
None.

## Notes considered and set aside (not findings)

- **REST/WS `error` failures aren't surfaced visually yet** (`postJSON` throws a generic message;
  `routeEvent`'s `error` case only `console.warn`s). Not flagged: there is nowhere to surface them
  *to* — the chat panel (where system/error lines belong, web_ui_spec §6.1) is wired in **v03.03**, not
  this version. Genuinely out of scope, not an oversight.
- **`openSocket` doesn't explicitly remove the old socket's listeners** before replacing `ws`. Not a
  real leak: the listeners are scoped to their own (now-closed, unreferenced) socket and become
  irrelevant once nothing points to it.

## What's solid
The `no-store` middleware matches the mount **exactly** (`"/ui"` or `"/ui/…"`), not a loose prefix — so
`/api/*` keeps normal caching and a hypothetical `/uixyz` is never stamped (a correctness detail
handled proactively per the reconcile note, not shipped as a gap). The static directory resolves from
`WEB_DIR` (this file's parent), so it works regardless of the process CWD, and the mount is added last
so it can't shadow the REST/WS routes. The shell is fully self-contained (system fonts, no CDN —
verified by a served-asset test) with real `<button>` cells for a11y. `app.js` shows the match id with
`textContent` (no injection) and never slices/substrings it (guarded by a test — a truncated id would
404 in the agent CLI), opens exactly one WebSocket, and guards every send on `readyState === OPEN`. No
model or secret is involved this phase.

## Architecture impact
None — §3/§8 (static mount + `no-store`) and §6.2 (the consumed protocol) implemented as documented;
no seam changed.
