## Highlights

- **Skeleton:** `pyproject.toml` pins `[tool.setuptools] packages = ["games","server","agent"]` up
  front, so `pip install -e ".[dev]"` succeeds instead of hitting the flat-layout "Multiple top-level
  packages discovered" error. Strict mypy + pytest configured as one source of truth in `pyproject.toml`.
- **Seam:** `GameInterface` matches architecture §4.1 exactly; the contract test pins abstractness +
  all four signatures. A Python 3.14 wrinkle surfaced during validation — annotations now evaluate to
  real objects, not strings — so the contract test compares against actual types (`dict[str, Any]`,
  `str | None`, etc.), fixed before the commit.
- **Engine:** `TicTacToe.apply_move` is the sole legality authority, rejecting out-of-range/occupied/
  wrong-type (with `bool` rejected *before* the int check so `True`/`False` can't pose as cell 1/0)
  and post-game-over moves, always returning `False`. `get_valid_moves` returns `[]` at a terminal
  (won) board even with empty cells remaining.
